# Catalogo prodotti per GitHub Pages

Versione finale con ultimi ritocchi.

## Modifiche incluse

- Box istruzioni subito sotto l'header, prima dei filtri
- Riepilogo carrello semplificato
- Nessuna quantità e nessun subtotale
- Ogni prodotto può essere aggiunto una sola volta
- Rimossi i pulsanti + e - nel carrello
- Mantenuto pulsante per rimuovere un prodotto dal carrello
- Copia riepilogo nel formato:
  Riepilogo carrello
  - Nome prodotto | prezzo
  Totale: totale
- Immagini cliccabili con popup fullscreen e X solo nel popup
- Pulsante Dettagli apre direttamente il link prodotto

## Colonne attese nel Google Sheet

- Nome articolo
- Tipo
- Prezzo
- Stato
- Note
- Link
- Immagine

## Requisiti

Il Google Sheet deve essere pubblico con permesso Visualizzatore.
Anche le immagini devono essere accessibili pubblicamente.
